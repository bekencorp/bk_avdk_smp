CLink
========

1.Introduction 
============
Clink or communication link facilitates bidirectional link to transmit
and receive messages between two entities/tasks. 
Clink infrastructure is based on MsgQueues handles transmit and reception
of messages between two tasks/functions. Clink event notification feature
enables to handles asynchronous events like reception of receive messages
through event notification handler

2. CLink Features
==================
- Inter task communication between two indepdendent application through
  shared memory, similar to host/device, client/server, master/slave
  kind of application.

3. CLink  source
==================================
CTests
├── core

4. CLink APIs
===============
The main important function are as followes
1) struct clink_t *create_clink(char *name, uint16_t queue_depth);
2) int connect_to_host(char *host_link_name, char *dev_link_name,
3) int clink_set_rx_notify(struct clink_t *clink, struct notify_event_t *rx_msg_notify);

5. CLink Example
==================
	 refer to tools/terminal_client/clink terminal application example,
  which is designed based on CLink, where the mshc-ctest is independent
  application running clink-host which creates  "clink-host" and to which
  independent terminal application (tools/terminal_client/clink) gets connect
  to clink-host and  communicate with mshc-host with put/get Msg inorder to provide
  terminal console user interaction with mshc-ctest application.

  The host/server/master application task create CLink communication link
  by create_link() API with specific name. say
	
  struct clink_t *host_link;
  int server_or_host_task()
  {
 	 host_link =  create_link ("clink-host", 256);
  }


  The device/client/device side application task just search for named link
  "clink-host" and gets connect, and start send/receive message to thru clink.

  
  struct clink_t *dev_link_handle, *host_link_handle;
  int client_or_device_task()
  {
	int retval;
 	 retval =  connect_to_host("clink-host", "clink-dev",
			host_link_handle, dev_link_handle);
  }

  Now client/device application can send or receive message using put_msg/get_msg 
  with server application/tasks.
   dev_link_handle->put_msg(dev_link_handle, &msg);
   dev_link_handle->get_msg(dev_link_handle, &msg);
