# DMA2D Example

* [English](./README.md)

## 概述
本示例展示了BK7258平台中DMA2D控制器的使用方法。它提供了二维图形操作功能，如用指定颜色填充区域、内存复制、像素格式转换和混合两个图像层。

## 支持的功能
 - **填充（Fill）**: 用指定颜色填充矩形区域
 - **内存复制（Memory Copy）**: 将图像数据从源地址复制到目标地址
 - **像素格式转换（PFC）**: 在不同像素格式之间转换（RGB565、RGB888、ARGB8888）
 - **混合（Blending）**: 混合前景和背景图层，可调节透明度


* DMA2D的功能在开发者指南中有详细介绍，请参阅：

  - `DMA2D开发指南 <../../../developer-guide/display/dma2d.html>`_

* 有关API参考，请参阅：

  - `DMA2D API <../../../api-reference/multimedia/bk_dma2d.html>`_\

## 组件
 - **bk_dma2d**: DMA2D控制器驱动
 - **frame_buffer**: 帧缓冲管理
 - **cli**: 用于测试的命令行接口


## 测试环境

   * 硬件配置：
      * 核心板，**BK7258_QFN88_9X9_V3.2**
      * PSRAM 8M/16M
      * lcd 转接小板
      * RGB接口的LCD，demo中使用的为st7701sn 480*854的屏幕

.. warning::

    请使用参考外设，进行demo工程的熟悉和学习。如果外设规格不一样，代码可能需要重新配置。


##  编译与运行

使用以下命令编译项目：

```
make bk7258 PROJECT=rgb_lcd_example
```

编译完成后，将生成的固件烧录到开发板上，然后通过串口终端使用以下命令测试显示功能：

命令执行成功打印："CMDRSP:OK"

命令执行失败打印："CMDRSP:ERROR"

## 命令行接口
本示例提供了命令行接口用于测试不同的DMA2D操作。以下是可用的命令：



### 基本命令
```bash
# 创建DMA2D控制器实例1
> dma2d open module1

# 关闭DMA2D控制器，释放资源并删除DMA2D实例1
> dma2d close module1

# 创建DMA2D控制器实例2,创建多个实例是为了多个场景下同时使用到DMA2D
> dma2d open module2

# 关闭DMA2D控制器，释放资源并删除DMA2D实例2
> dma2d close module2
```

### 填充命令
```bash
# 用指定颜色填充区域，该命令会执行两个实例的填充操作
# 格式: dma2d fill <格式> <颜色> <帧宽度> <帧高度> <x坐标> <y坐标> <填充宽度> <填充高度>
# <格式>: RGB565, RGB888, ARGB8888
# <颜色>: 十六进制颜色值
> dma2d fill RGB565 0xF800 320 240 0 0 320 240
```

### 内存复制命令
```bash
# 从源地址复制图像数据到目标地址，该命令会执行两个实例的内存复制操作
# 格式: dma2d memcpy <格式> <颜色> <源宽度> <源高度> <目标宽度> <目标高度> <源x坐标> <源y坐标> <目标x坐标> <目标y坐标> <宽度> <高度>
> dma2d memcpy RGB565 0xF800 320 240 320 240 0 0 0 0 320 240
```

### 像素格式转换命令
```bash
# 转换像素格式，该命令会执行两个实例的像素格式转换操作
# 格式: dma2d pfc <输入格式> <输出格式> <颜色> <源宽度> <源高度> <目标宽度> <目标高度> <源x坐标> <源y坐标> <目标x坐标> <目标y坐标> <宽度> <高度>
> dma2d pfc RGB565 RGB888 0xF800 320 240 320 240 0 0 0 0 320 240
```

### 混合命令
```bash
# 混合前景和背景图层，该命令会执行两个实例的混合操作
# 格式: dma2d blend <前景格式> <背景格式> <输出格式> <背景颜色> <前景颜色> <背景宽度> <背景高度> <前景宽度> <前景高度> <目标宽度> <目标高度> <背景x坐标> <背景y坐标> <前景x坐标> <前景y坐标> <目标x坐标> <目标y坐标> <宽度> <高度> <透明度>
# <透明度>: 十六进制透明度值 (00-FF)
> dma2d blend RGB565 RGB565 RGB565 0x07E0 0xF800 320 240 160 120 320 240 0 0 80 60 0 0 160 120 FF
```


## 注意事项
- 执行操作前确保已打开DMA2D控制器
- 操作完成后关闭并删除DMA2D控制器
- 示例使用从显示内存分配的帧缓冲区
- 所有操作均以同步模式执行
