# iperf

* [English](./README.md)

## 1. 概述

集成 STA / SoftAP / 扫描 / iPerf 等 CLI 的综合 Wi-Fi 测试工程。

- 开发者指南：[Wi-Fi iPerf](../../../../developer-guide/wifi/bk_wifi_iperf.html)、[Wi-Fi 模式与 CLI](../../../../developer-guide/wifi/bk_wifi_mode.html)

## 2. 编译

```text
make bk7259 PROJECT=wifi/iperf
```

## 3. 运行

先通过 CLI 完成 STA 或 SoftAP 联网，再执行 iPerf 相关命令。详见开发者指南。
