## Overview

Combined Wi-Fi test project with STA/SoftAP/scan/iPerf CLI commands.

- Guides: [Wi-Fi iPerf](../../../../developer-guide/wifi/bk_wifi_iperf.html), [Wi-Fi Mode & CLI](../../../../developer-guide/wifi/bk_wifi_mode.html)

## Build

```text
make bk7259 PROJECT=wifi/iperf
```

## Run

Connect via STA or SoftAP CLI first, then run iPerf commands. See the developer guide.
