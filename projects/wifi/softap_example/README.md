# softap_example

* [中文](./README_CN.md)

## Overview

SoftAP start demo with AP connected/disconnected events.

- Source: `ap/ap_main.c`
- Guide: [Wi-Fi Mode & CLI](../../../../developer-guide/wifi/bk_wifi_mode.html)

## Build

```text
make bk7259 PROJECT=wifi/softap_example
```

## Run

AP UART: ``ap myssid 12345678`` — CP UART: ``ap_cmd ap myssid 12345678``
