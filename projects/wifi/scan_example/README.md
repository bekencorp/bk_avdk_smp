# scan_example

* [中文](./README_CN.md)

## Overview

Demonstrates ``bk_wifi_scan_start`` and ``EVENT_WIFI_SCAN_DONE`` with result dump.

- Source: `ap/ap_main.c`
- Guide: [Wi-Fi Scan](../../../../developer-guide/wifi/bk_wifi.html) (Scan section)

## Build

```text
make bk7259 PROJECT=wifi/scan_example
```

## Run

AP UART: ``scan`` — CP UART: ``ap_cmd scan``
