# rlk_demo

* [English](./README.md)

## 1. 概述

BK-RLK 原链路（Raw Link）演示工程，含 ping / iperf 等 CLI。

- 开发者指南：[BK-RLK 使用指南](../../../../developer-guide/wifi/bk_rlk.html)
- API：[BK-RLK API](../../../../api-reference/wifi/bk_rlk.html)

## 2. 编译

```text
make bk7259 PROJECT=wifi/rlk_demo
```

## 3. 运行

烧录后通过 AP 核 CLI 进行 RLK 配对与吞吐测试。
